# ShiftJolt

Watches financial transactions and generates dashboards to track swap and liquidity pools in real time for cryptocurrency traders.

With ShiftJolt, you get a lightweight tool that stays out of your way.

**What you get**

- Watches financial transactions and generates
- dashboards to track swap and
- liquidity pools in real time

## Key Features

- Watches financial transactions and generates
- dashboards to track swap and
- liquidity pools in real time

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ShiftJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ShiftJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
